Dialogs, dropdowns, menus, cards, tabs, and form fields now use the shared Omni components, so they match the rest of Omni. Deleting a schema or revoking a token now confirms in the shared confirmation dialog, which shows progress and any error while the action runs. Menu items show a pointer, and dialogs keep a gutter on phones.

Press `?` anywhere, or pick "Keyboard shortcuts" in the command palette, to see every keyboard shortcut.
